## ⬇️ Download

Download the latest **Quick Windows installer (.exe)** from [GitHub Releases](https://github.com/m-7-m/quick/releases/latest).

## ✨ Features

- 🗂️ **Custom app profiles** — Create profiles with the apps you want, then install a profile's apps together.
- 🔄 **Import and export profiles** — Export custom profiles to JSON to back them up or share them, and import them again whenever you need them.
- 📦 **Built-in profiles** — Get started with ready-made app collections for common needs.
- 🔎 **App management** — Search and browse apps, view installed apps, and uninstall apps.
- 🚀 **Updates** — Check for available app updates and update apps individually or all at once.
- 🖥️ **System tray** — Keep Quick in the tray and reopen its window when needed.

## 🧰 Requirements

- 🪟 Windows
- 📥 [WinGet](https://learn.microsoft.com/windows/package-manager/winget/) available on your system

Quick is distributed as a ready-to-install Windows executable. You do not need Node.js, npm, Rust, or Cargo to install or use it.
